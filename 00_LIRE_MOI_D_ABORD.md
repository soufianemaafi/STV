## 💡 CE QUE VOUS DEVEZ SAVOIR

### STV en 3 mots
**Lecteur vidéo Android** qui :
- Lit HLS, DASH, MP4, etc.
- Montre des pubs (AdMob)
- S'intègre avec d'autres apps

### Architecture en 3 couches
```
├─ PRÉSENTATION (Compose UI)
├─ MÉTIER (ViewModels + Controllers)
└─ SERVICES (ExoPlayer, AdMob)
```

### Composants clés
| Composant | Rôle |
|-----------|------|
| MainActivity | Écran d'accueil |
| PlayerActivity | Lecteur vidéo |
| ExoPlayer | Streaming |
| AdManager | Annonces |
| StateFlow | Réactivité données |

### Comment l'utiliser
```
Utilisateur → Saisit URL → Clique LIRE → Vidéo joue
```

### Comment l'intégrer
```
SoukiTV → Intent → STV reçoit URL → Vidéo joue
```
